# Nindova v0.1.0 — Rasoi Pairs

Nindova’s first GitHub release replaces the original experimental arc with **Rasoi Pairs**, a calm, bounded pair-removal game made from everyday Indian kitchen forms.

## Highlights

- 36 tiles, nine motifs, three shallow racks, and one readable free-edge rule.
- Exhaustive verification of all 343 reachable states: one ending, zero dead states.
- No score, count, timer, streak, grade, collection, randomized reward, or promoted replay.
- Native tile buttons, visible names, keyboard operation, 44px targets, 200% zoom, and reduced motion.
- Hidden wind-down and hard fifteen-minute closure.
- Same-night deterministic replay and same-tab resume without long-lived interaction history.
- First-light Rasoi Dawn with local still and optional silent loop.
- Standalone HTML plus a composed website/docs/offline-PWA bundle.

## Downloads

- `nindova-v0.1.0.html` — self-contained Session; open directly in a current browser.
- `nindova-web-v0.1.0.zip` — landing page, documentation, `/play/` PWA, and standalone file; serve over HTTP for installation/offline behavior.
- `SHA256SUMS.txt` — SHA-256 digests for both artifacts.

## Evidence and limits

Chromium automation verifies the exhaustive engine, full browser arc, responsive layouts, keyboard path, reduced motion, 200% zoom, local migration, Dawn, same-origin PWA/offline behavior, and standalone independence. The real wall-clock production run is recorded separately in `docs/testing/m6-release-hardening.md`.

This is a behavioral design study, not a sleep tracker or treatment. Rasoi Pairs has not been clinically shown to make people sleepy, produce a specific dopamine response, or improve sleep. Human Punjabi cultural-authenticity review, real-device VoiceOver/TalkBack acceptance, broader installed Safari/Android proof, and public website deployment remain open limitations. The iOS Wall is not included.
