# Nindova v0.4.2 — Clean Return

Nindova v0.4.2 keeps an unfinished table's return context intact across cancellation, makes Escape focus deterministic in both confirmation dialogs, and strengthens proof that Sector Sprint is playable from its first Action gate through its fifth-Act curtain call.

## Highlights

- Cancelling a browser-Back leave request no longer discards the requested category position. Retry the visible Back control, confirm the leave, and the House returns to the same scrolled table context.
- Button and Escape cancellation share one leave path. Focus returns to the visible table Back control even when WebKit provides no useful native dialog invoker.
- Gallery clear Escape is normalized to an explicit cancellation and returns focus to **Clear this Gallery** without changing a reading.
- The House browser pilot now clears every real Sector Sprint Action Act and reaches **Roti Relay** and the authored curtain call. The complete three-beat-per-Act Narrated route remains independently verified.
- The README, landing page, dedicated Sector Sprint guide, accessibility/testing docs, source media, package versions, and House PWA cache are synchronized from the release candidate.

## Evidence boundary

The release candidate runs the complete code and browser matrix, including all eight House completions, Sector Sprint Action and Narrated play, cancel→retry→leave scroll continuity, button/Escape focus restoration, phone/desktop layouts, keyboard and nonvisual operation, 200% zoom, reduced motion, same-origin runtime capture, cold-offline House and Night entry, and standalone Night independence. A separate Playwright WebKit pass covers both corrected dialog dismissals on a mobile surface. Automation does not establish human enjoyment, representative Sector Sprint difficulty, real-device assistive-technology acceptance, installed Safari/Android PWA behavior, representative cultural review, or physical-device QR scanning.
