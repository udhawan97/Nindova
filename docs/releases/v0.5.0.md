# Nindova v0.5.0 — Illustrated House

Nindova opens onto a lantern-lit courtyard, with five illustrated Salon doors and richer materials throughout the games. Sector Sprint gains deeper scenery while caching its expensive background painting.

## Highlights

- Original, local vector artwork gives the House a moonlit courtyard and each category its own miniature. Brass controls, dimensional Pattern Court pieces, a deeper Mirror Forge setting, and a carved Rasoi tray carry the visual direction into play.
- The Night Room's nine kitchen motifs have more detail, ivory tile edges, and clearly shaded covered tiles.
- Sector Sprint adds layered foothills, lunar detail, and recessed Chandigarh shopfronts. Its sky and three parallax strips are cached for the current Act, quality tier, and viewport, with explicit backing-store release and a direct-paint fallback.
- This release also includes the Session closure and resume fixes recorded in v0.4.4, plus subsequent navigation, responsive-layout, and tactile interaction improvements. The earlier v0.4.4 tag was not published as a downloadable GitHub release.

## Verification

The candidate passes 146 unit tests and the rendered House, standalone Night, and PWA journeys, including all eight games, the complete Action and Narrated Sector Sprint routes, keyboard and reduced-motion paths, responsive layouts, local-state recovery, and cold-offline entry.

The release verification measured Sector Sprint frame intervals at 17.7 ms p95 on desktop and 17.7 ms p95 in a 375 × 812 viewport with 4× CPU throttling. Maximum sampled lane response was 38.7 ms. All existing performance budgets passed. These are local automated observations, not physical-device or universal frame-rate guarantees. The scenery cache stays below 25 MiB at 2× scale; static House artwork adds no continuous animation loop.

## Release files

- `nindova-v0.5.0.html` — portable standalone Night Room.
- `nindova-web-v0.5.0.zip` — complete root-hosted static website, docs, House PWA, Night PWA, and standalone Night file. Unzip and serve over HTTP; PWA installation requires a secure origin.
- `SHA256SUMS.txt` — SHA-256 checksums for both downloads.

Runtime requests remain same-origin and static. State stays local, with no telemetry. Authored routes, collision geometry, optional sound, accessibility alternatives, and the bounded Night ending are preserved. The native iOS Wall remains deferred. Physical-device thermal, touch, and assistive-technology acceptance are not established by these automated checks.
