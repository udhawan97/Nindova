# Nindova v0.2.0 — Quiet Depth

Nindova v0.2.0 adds a little more thinking without turning bedtime into a competition. The nightly Session stays bounded, local, and genuinely willing to end.

## Added

- Gentle and Deeper Masala Mound profiles: two equal, tonight-only 36-Tile choices with real three- and four-layer occlusion.
- One deterministic brass-bloom response for legal pairs, with optional sound and an opacity-only reduced-motion alternative.
- Primary Rest plus optional Rasoi Image Drift, a response-free three-object handoff with no route back into play; closing and deliberately reopening can begin another separately bounded same-night Session.
- Apache License 2.0, redistributed font notices, and a direct non-tracking QR artifact for the canonical `/play/` route.

## Improved

- Exhaustive board verification covers 382 Gentle and 517 Deeper reachable states, one terminal state each, and zero dead states.
- Tile semantics distinguish covered-from-above, blocked-on-both-sides, free, selected, and settled states.
- Recipe version 4 identifies each board profile. Long-lived Dawn remains version 3; version-4 same-tab records restore a profile and reject stale or unknown-profile active state without creating performance history.
- Public documentation and rendered media now match the layered game and its evidence boundary.

## Evidence boundary

- Masala Mound uses recognition, visual search, and spatial planning. It is not proven to improve general memory.
- Nindova is not proven to make people sleepy, improve sleep, or produce a useful dopamine response.
- No weekly rank, score, streak, personal best, history, sleep grade, memory grade, or improvement claim is included. Optional sleep education is paraphrased, attributed, population-level, and outside the nightly Session.
- A pinned GitHub Pages workflow publishes the static build from `main`. The canonical route, rendered QR destination, service-worker control, same-origin requests, and offline reload are browser-verified; a physical-device QR scan remains unverified.
