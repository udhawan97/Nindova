# Nindova v0.2.0 — proposed candidate notes

These notes describe the verified source candidate. v0.2.0 is not a published tag or GitHub release until the release gate is run separately.

## Added

- Masala Mound: 36 kitchen Tiles across 24 base, 8 middle, and 4 top positions with real layered occlusion.
- One deterministic brass-bloom response for legal pairs, with optional sound and an opacity-only reduced-motion alternative.
- An optional screen-away handoff and a neutral path back to intake for another separately bounded same-night Session.
- Apache License 2.0, a direct non-tracking QR for the canonical Pages `/play/` route, and a static GitHub Pages workflow.

## Improved

- Exhaustive board verification now covers 382 reachable states, one terminal state, and zero dead states.
- Tile semantics distinguish covered-from-above, blocked-on-both-sides, free, selected, and settled states.
- Recipe version 3 preserves existing recipe-two Rasoi Dawn data while rejecting stale active-board state.
- Public documentation and rendered media now match the layered game and its evidence boundary.

## Evidence boundary

- Masala Mound uses recognition, visual search, and spatial planning. It is not proven to improve general memory.
- Nindova is not proven to make people sleepy, improve sleep, or produce a useful dopamine response.
- The Pages workflow and QR remain unverified as a live public route until publication is observed.
