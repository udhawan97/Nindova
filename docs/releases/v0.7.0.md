# Nindova v0.7.0 — The Long Way Home

Nindova’s Salon games now explain their goal and controls before play. Pattern Court becomes a five-part construction table with loose pieces, swaps, undo, reset, precise conflict feedback and optional one-piece assistance.

The Chandigarh table is now **Chandigarh: The Long Way Home**, an ordered outing from a Sector 22 verandah to the Sector 17 pedestrian plaza. The action route combines walking, jumping, route choice and a three-signal scarf-deflection encounter. The narrated route carries the same encounters and outcome without movement, timing, sound or visual interpretation. Real Chandigarh notes are separated from the fictional people, errand and courtyard toy.

The ten-minute foreground boundary, local-only state, zero telemetry, finite five-part structure and the Night Room’s Two-Loop contract are unchanged. Automation verifies deterministic rules, the five inlay puzzles, both Chandigarh routes, phone and desktop layouts, keyboard use, reduced motion, same-origin requests, standalone Night output and both offline PWAs. It does not establish human enjoyment, cultural authenticity, physical-device performance or real-device assistive-technology acceptance.
