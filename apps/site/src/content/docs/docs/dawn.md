Dawn is Nindova’s only between-Session pull. It does not appear at night, and no notification asks a person to return.

## Eligibility

Dawn is available from 06:00 through 11:59 on the completed Session’s captured Dawn date. Evaluation uses the IANA time zone captured when that Session began, even if the device later travels or changes zones.

Before 06:00, from noon onward, on another date, without a completion, or after corrupt-state recovery, no stale Dawn is shown.

## First light

For a Rasoi completion, Dawn uses the exact stored motif order and lays the nine kitchen forms on brass plates in a warm first-light kitchen. It shows no score, count, grade, attendance mark, or completion badge.

Version 1 and version 2 Vista completions migrate to a labeled legacy Dawn composition during their original eligibility window. The migration does not pretend an old Vista was a Rasoi board.

## Keepsakes

- **Save still** creates a local PNG from the rendered canvas.
- **Share still** invokes explicit browser file sharing when available.
- **Make silent loop** records a subtle three-second canvas loop in a supported MP4 or WebM format.

If loop recording is unsupported or fails, Dawn and the still remain usable. Cancelling sharing leaves Dawn open. Temporary object URLs are revoked when replaced, closed, or unloaded.
