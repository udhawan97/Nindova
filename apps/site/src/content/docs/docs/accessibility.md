Grand Salon and Rasoi Pairs use native HTML controls for every required action. Salon rerenders deliberately restore logical focus after a category choice, classic-study move, answer, Lantern cover, Stack move, Sector Sprint story beat, chapter transition, and curtain call. Navakankari and Aadu boards expose complete screen-reader position and line-relationship descriptions plus lettered 44px destination buttons; Pallanguzhi exposes both rows' seed counts, sowing order, each authored outcome, and lettered 44px starting pits. Stack plinths announce the ordered discs and current top disc; visible geometry is not the only state source.

Sector Sprint's Canvas Action route advances automatically and exposes native Move up, Move down, Act tool, Pause, and Narrated route controls. One fresh Up or Down press moves one adjacent lane; held input and keyboard repeat do nothing. Every gate warning combines position, arrow shape, and text, and every safe lane is no more than one move from the previous one. One architectural contact ends that Action attempt and moves focus to Retry when a complete attempt still fits, otherwise to Continue narrated. Underlying Canvas controls are removed during recovery, and no failure history is stored. A large external next-passage cue, nonnumeric action-status labels, and the live region report Canvas information in text without announcing every frame. Reduced motion starts directly in the complete three-beat-per-Act text route, which reaches the same deterministic curtain call and requires no timed response, precision, sound, animation, or visual interpretation; speech and sound never autoplay. Pause holds active time for either route while narrated beat controls remain available and Pause persists between narrated Acts; paused narration does not play the optional chime. An unfinished route that reaches the absolute boundary, including during an Act transition or recovery choice, or reloads without its in-memory clock closes without claiming completion.

The Salon's visual Pattern and Mirror tasks are entertainment, not equivalent cognitive measurements. Text alternatives preserve operation and state, but no claim is made that an altered presentation measures the same construct.

## Operable rule

- Free tiles are the only tiles in the keyboard tab order.
- Each tile announces its kitchen form, numbered layer, and whether it is free, covered from above, blocked on both sides, selected, or settled.
- Selection and removal work with pointer, touch, keyboard, switch-style activation, and programmatic semantic control.
- All tile and toolbar targets are at least 44 by 44 CSS pixels.
- Live status text describes selection, mismatch, match, help, automatic settlement, and closure.
- Visible text names mean recognition does not depend on the illustration.

The profile selector uses native radio controls, visible descriptions, and explicit three- versus four-layer language, so the distinction does not rely on geometry or color alone. Image Drift exposes all three object names in a semantic list and invites imagery or tactile memory; it is always skippable.

Audio is off by default and optional. The brass bloom and board-to-dabba transition are decorative; reduced motion replaces translation and scale with short opacity changes. Precision movement, mental imagery, sound, animation, and vision are not required.

## Alternate presentation

The House and Night surfaces are browser-verified at 320×568, 375×812, 414×896, 768×1024, and 1440×900. Coverage includes House keyboard game paths and focus restoration, Sector Sprint touch-sized controls and narrated route, Night keyboard pairing, 200% page scale, reduced motion, target size, visible focus, and horizontal overflow.

Real-device VoiceOver and TalkBack acceptance remains an untested release limitation. Automated semantic checks are not a substitute for that human proof.
